**Merge order inside Phase 2**, derived from the dependencies above:

1. **Independent once the gate passes:** A1 (done as PILOT-1), A2, A3, B1, B2, C1 (done as PILOT-2).
2. **After PILOT-2:** B3, C2, D1.
