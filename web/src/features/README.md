# Adding a FinSight island

Do not start panel migration until I1 and both pilots have passed the plan's gate.

1. Read PLAN.md §0–§2, your card, and your section in COUPLING.md. Record the baseline commit and every caller/global/timer/DOM id assigned to the card. If COUPLING.md is absent, stop before panel work.
2. Use one `mig/<card>` branch and isolated worktree from main. Read server producers for response types; append missing shared types, query hooks and invalidation rows in their registries. Reuse existing hooks rather than duplicating polls.
3. Put your component and scoped CSS in `features/<name>/`. Import formatting and UI primitives from `ui/`. Use `useStore(window.FinSight.store, selector)` for UI state and the account/base-keyed Query hooks for server data. Pass Query's AbortSignal. Respect auth/account readiness, polling cadence and disabled background intervals. Never store a fetched portfolio in Zustand.
4. Export a default component and append its lazy loader to `islands.ts`. Do not statically import the component into main. The clock is the minimal reference. `_probe/` is test-only and must remain outside the registry and index.html.
5. Keep the legacy `.panel[data-pid]` and `.panel-head` intact. Replace only the body with `<div data-island="your-id"></div>`. For header controls add `<span data-island-slot="your-id:head"></span>` and render `PanelHeadSlot` from the body component. `PanelBody` never renders `.panel`. Keep IDs, keyboard behavior, focus order and labels needed by callers/tests.
6. Redirect **every** external caller listed in COUPLING.md before deleting its legacy symbols. Selection goes through the store; mutations use the shared invalidation map/bus so retained legacy readers and Query both refresh. Register legacy refreshers using `bus.on(key, fn)` and retain the returned disposer. Do not remove unrelated legacy boot or polling calls.
7. Each component cleans its timers, subscriptions and requests on unmount. The runtime owns createRoot/unmount; do not create another root in a panel. Moving a host retains its root. Removing it unmounts after the mutation microtask. Lazy-load/render errors are contained by IslandBoundary, with a reload message; other islands remain active.
8. Add the card E2E and cover its COVERAGE.md rows. Prove drag/hide/reload, lock/unlock, account/base changes and one polling subscription as applicable. Preserve baseline assertions. Test error/empty/manual assets and mutation fan-out before claiming parity.
9. `npm ci`, `npm run build`, then `npm run verify` on Node 24. Commit source plus public/app output. If the manifest file set changes, bump the service-worker SHELL per §1.5. Review snapshots before updating them and record measurements against BASELINE.md.
10. Check `git diff --stat main` including staged/new files, record exact results and limitations, commit as `mig(<card>): …` under the owner's identity with no co-author, and never push. Integration uses one `--no-ff` merge per verified card under owner authorization.
