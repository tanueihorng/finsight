# Start here

For setup and usage, follow [Quick start in the README](README.md#-quick-start).
For code changes, read [AGENTS.md](AGENTS.md), then the [documentation index](docs/README.md).

The server requires Node.js 24 or newer. From this folder, `node server.ts` starts the terminal.
`npm run demo` uses synthetic data. See the README and agent guide before configuring Kestrel.

The former setup guide is preserved in [the archive](docs/archive/20261027-START-HERE.md).
